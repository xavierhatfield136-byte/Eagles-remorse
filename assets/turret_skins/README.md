# Turret Skin Drop Folder

Drop turret/system sprites here:

- `assets/turret_skins/`

Supported style keys:

- `twin_gun`
- `heavy_triple`
- `missile_pod`
- `beam_emitter`
- `stealth_flush`
- `ciws`

Optional naming variants (first match wins):

1. `<faction>/<role>_<style>.png`
2. `<role>_<faction>_<style>.png`
3. `<role>_<style>.png`
4. `<faction>/<style>.png`
5. `<style>_<faction>.png`
6. `<style>.png`
7. `default_<faction>_<style>.png`
8. `default_<style>.png`
9. `default_<faction>.png`
10. `default.png`

Faction keys:

- `ally`
- `enemy`
- `team_c`
- `team_d`

- `picket`

- `stealth_ship`

- `hauler`
- `base`

Art requirements:

- PNG with alpha (transparent background)
- Turret points right (+X)
- Centered in canvas
- Recommended source canvas: `512x512`
