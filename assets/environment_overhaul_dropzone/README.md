# Environment Overhaul Drop Zone

Drop new environment graphics into this folder.

## Folder layout

- `assets/environment_overhaul_dropzone/background/`
- `assets/environment_overhaul_dropzone/asteroids/`

## Recommended background files

- `bg_space_base_tile_4096.png` (seamless)
- `bg_nebula_overlay_tile_4096.png` (seamless)
- `bg_star_overlay_tile_2048.png` (seamless)
- `bg_dust_overlay_tile_2048.png` (seamless)

## Recommended asteroid files

- `ast_small_01.png` ... `ast_small_08.png`
- `ast_medium_01.png` ... `ast_medium_08.png`
- `ast_large_01.png` ... `ast_large_08.png`
- `ast_ore_small_01.png` ... `ast_ore_small_08.png`
- `ast_ore_medium_01.png` ... `ast_ore_medium_08.png`
- `ast_ore_large_01.png` ... `ast_ore_large_08.png`

## Requirements

- PNG format
- Background files must be seamless/tileable
- Asteroids must use transparent backgrounds (alpha)
- No text or watermark
