# How To Open Codex Via The Command Prompt

## Open Codex In This Project
```bat
cd "C:\Users\xhatf\IdeaProjects\game"
codex --full-auto
```

## Other Helpful Commands
```bat
cd /d C:\Users\xhatf\IdeaProjects\game
dir
codex --help
codex --version
git status
```

## Notes
- Use `cd /d` so Command Prompt can switch drive + folder in one step.
- Run commands from the project root (`C:\Users\xhatf\IdeaProjects\game`) for best results.
