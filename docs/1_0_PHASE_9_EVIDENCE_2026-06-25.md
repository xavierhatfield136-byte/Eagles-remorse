# Phase 9 Evidence - Performance And Maximum Battle Scale

Date: 2026-06-25

## Status

Phase 9 is complete for the alpha checklist.

The important correction from the first pass is that `160` ships per side is now
recorded as a stress scenario, not promised as the supported alpha battle scale.
The supported FPS envelope is:

- ordinary tactical play: `14` ships per side / `28` total authored combatants;
- largest supported battle: `50` ships per side / `100` total authored
  combatants;
- stress-only reports: `100` ships per side and `160` ships per side.

The FPS-certified runs use explicit `Low` visual detail and Tactical FPS View.
This keeps the normal rich presentation available while giving minimum hardware
a clear performance mode.
