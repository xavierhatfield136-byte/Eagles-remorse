# Eagles Remorse Known Issues

## Alpha Known Issues

- EXE installer builds are skipped locally when WiX is not installed.
- Linux packages are currently x86-64 only; ARM64 builds are not yet provided.
- Steam packaging is intentionally deferred until a Steamworks app, depot, and
  branch setup exist.
- Minimum-hardware validation is represented by local guardrail harnesses and
  still benefits from external tester confirmation on varied machines.
- Some late-campaign balance values may still need owner/playtester tuning.

## Not Release Blockers For This Phase

- Post-release stretch systems such as editors, multiplayer, replay tooling, and
  workshop-style distribution remain outside the 1.0 alpha target.
- The source repository remains source-available under the project license;
  public player artifacts are provided for Windows, x86-64 Linux, and macOS.
