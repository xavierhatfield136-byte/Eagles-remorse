# Eagles Remorse Known Issues

## Windows Steam Candidate — Known Limitations

- Steam upload and Steam-client acceptance still require owner-created AppID,
  Windows depot, branch, and Steamworks permissions.
- Minimum-hardware validation is represented by local guardrail harnesses and
  still requires external confirmation on the published minimum machine.
- Some late-campaign balance values may still need owner/playtester tuning.
- Exact synthesis engine/voice terms for the replacement robot/TTS WAV files must
  be documented before paid release.

## Not Release Blockers For This Phase

- Post-release stretch systems such as editors, multiplayer, replay tooling, and
  workshop-style distribution remain outside the initial Steam scope. Multiplayer
  is hidden in the public configuration.
- The source repository remains source-available under the project license;
  the initial Steam release advertises Windows only. Existing Linux/macOS package
  tasks do not imply those platforms are supported on Steam.
