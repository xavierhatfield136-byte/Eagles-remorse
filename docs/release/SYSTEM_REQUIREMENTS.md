# Eagles Remorse System Requirements

## Proposed Minimum — Windows Steam Candidate

- OS: Windows 10/11 64-bit
- Runtime: bundled Java 21; no separate JDK/JRE required for packaged builds
- CPU: modern dual-core x64 CPU
- Memory: 8 GB RAM
- Graphics: integrated GPU capable of 1280x720 desktop rendering
- Storage: 2 GB free space for package, extracted runtime, logs, and saves
- Display: 1280x720 minimum

## Proposed Recommended

- OS: Windows 11 64-bit
- CPU: recent quad-core x64 CPU
- Memory: 16 GB RAM
- Graphics: discrete GPU or recent integrated GPU
- Display: 1920x1080

## Notes

- Use the in-game `Low` visual detail option and Tactical FPS View for minimum
  hardware performance checks.
- Saves and logs are written to the user's application-data directory, not the
  install directory.
- These values are conservative release-candidate targets, not final Steam claims.
  Confirm or raise them after testing the Steam-installed build on representative
  minimum hardware. Linux and macOS packages are not part of the initial Steam scope.
