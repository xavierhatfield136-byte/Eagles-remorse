# Eagles Remorse 1.0.0 Alpha 1

This is the first broadly distributable alpha build of Eagles Remorse.

## Downloads

- Windows installer: `EaglesRemorse-1.0.0.exe`
- Windows portable build: `EaglesRemorse-1.0.0-alpha.1.zip`
- Linux portable build: `EaglesRemorse-1.0.0-alpha.1-linux-x64.tar.gz`

All packages include a Java 21 runtime. Players do not need to install Java.

## Highlights

- Persistent strategic campaign with sector travel, territorial conquest,
  faction fleets, stations, resources, trade, and tactical site entry.
- Full tactical ship combat with carriers, capitals, titans, internal damage,
  crew stations, power management, tactical map, and x-ray views.
- Rebuilt Command School covering both the overworld campaign layer and
  in-mission controls in a safe training environment.
- Native full-detail ship rendering plus player-selectable simplified fleet
  rendering for very large battles.
- Accessibility, input-remapping, save compatibility, performance guardrails,
  release validation, and user-writable save/log paths.

## Alpha Expectations

This build is feature-complete enough for alpha playtesting, but balance,
late-campaign pacing, and hardware-specific performance still need broad player
feedback. Save compatibility is best effort during the alpha series.

See `KNOWN_ISSUES.md` and `SYSTEM_REQUIREMENTS.md` for current limitations and
hardware guidance.
