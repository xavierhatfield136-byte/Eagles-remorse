# First-Hour Experience

## Campaign Briefing

New Campaign Ops runs use a paced, non-blocking command briefing. It teaches movement, mining, docking, map use, fleet management, first contact resolution, strike evaluation, shortage recovery, and checkpoint behavior one beat at a time.

- `Ctrl+F1`: skip the current beat independently.
- `Ctrl+F2`: open or close the replayable briefing archive.
- Reminders appear only after the current beat has been idle for 42 seconds.
- Checkpoint saves show a visible confirmation banner.

Command School remains available from the main menu as a replayable tactical sandbox.

## Difficulty

Open **Difficulty And Accessibility** on the main menu to select a preset or tune systems independently.

- **Relaxed Campaign**: reduced attrition, lethality, and hostile escalation.
- **Tactical Only**: launches battles without campaign logistics.
- **Command Only**: strategic contacts auto-resolve instead of opening tactical battles.
- **Iron Command**: harsher losses and checkpoints limited to sector transitions.
- **Custom**: individually adjusts command complexity, combat lethality, strategic pressure, and attrition.

## Accessibility

The same menu provides colorblind palettes, scalable HUD/subtitle text, a high-contrast HUD frame, reduced flash, reduced screen shake, subtitle background and speaker-label controls, pause on focus loss, and hold-versus-toggle settings for mining, firing, and map use.
